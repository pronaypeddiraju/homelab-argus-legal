Privacy Policy

homelab-argus · last updated 16 November 2026

Who this covers

homelab-argus is a personal-use application operated by a single individual, used only by that same individual on infrastructure they control. It is not distributed, has no other users, and is not offered as a service.

What Google user data is accessed

DataAccessWhy
Gmail messagesRead-onlyTo find and summarise purchase receipts and order confirmations
Google CalendarRead-onlyTo review the owner's own schedule
Google Drive filesRead-onlyTo locate invoices and warranty documents

The application requests no write, send, or delete access of any kind.

How the data is used

Accessed data is used solely to answer the owner's own questions and to produce summaries for the owner — for example, a list of recent receipts. No data is used for advertising, profiling, or any purpose beyond serving the owner.

Where it is stored

Processing happens on the owner's privately operated server. OAuth credentials are stored on that server as files readable only by the owner's system account. No copy of Google user data is sent to any third party, and no cloud storage provider is used.

Sharing

None. Data is not sold, rented, transferred, or disclosed to any third party. The application contains no analytics, no telemetry, no advertising, and no third-party SDKs. Summaries are delivered only to the owner, through a private messaging channel the owner controls.

Limited Use

homelab-argus's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Message content is not retained after a request is answered; only the fields needed for the owner's records (such as merchant, date, and amount) are kept. Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's access. Revoking access also invalidates the stored credentials.

Changes

Any change to this policy will be published on this page with an updated date.
